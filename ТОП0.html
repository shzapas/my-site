📉 ТОП 0 — Снижение цены

Краткая инструкция

🚀 Порядок работы

  • 1. Загрузите Гамму (и при необходимости Условия поставщиков)
  • 2. Нажмите 🧮 РАССЧИТАТЬ — построится таблица
  • 3. Примените фильтры: ТОП, Статус, Условие, Подотдел
  • 4. Отметьте чекбоксами нужные артикулы
  • 5. Задайте целевую маржу %
  • 6. Нажмите ⚡ ПРИМЕНИТЬ К ВЫДЕЛЕННЫМ
  • 7. Колонки «Нов ПЦ» и «Нов МАРЖ» заполнятся

📤 Две кнопки выгрузки

  • 📤 ВЫГРУЗИТЬ СВОДНУЮ (без изменений) — выгружает всю сводную таблицу как есть, без применённых цен. Пользователь может сам поковыряться в Excel.
  • ⬇️ ВЫГРУЗИТЬ С ИЗМЕНЕНИЯМИ — выгружает только артикулы с применённой маржой. Кнопка находится в панели с ползунком.

📊 Как считается маржа

  • Закуп + НДС = Цена DPAC × 1.22
  • Маржа % = ((ПЦ − Закуп с НДС) / ПЦ) × 100%
  • Нов ПЦ = Закуп с НДС / (1 − Целевая маржа / 100)
  • Нов МАРЖ = ((Нов ПЦ − Закуп с НДС) / Нов ПЦ) × 100%

⭐ Условие

  • снижение, если ПЦ ≥ РРЦ
  • нет, если ПЦ < РРЦ

🎯 Особенности

  • Магазины определяются автоматически из Гаммы
  • Исключаются артикулы с нулевым запасом по всем магазинам
  • +100 строк — кнопка внизу таблицы
  • Разные проценты — можно применять к разным группам
