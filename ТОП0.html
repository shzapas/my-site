📋 Три вкладки

⏰ AVS Прогноз

  • Дата AVS в будущем, ТОП ЦО ≠ 1
  • Излишек = Запас(дн) + Путь(дн) − Дней_до_AVS
  • Магазин = Все → блоки по магазинам
  • Магазин выбран → плоская таблица по этому магазину
  • Колонка Наполненность = запас / вместимость × 100%

📊 Маржа

  • Закуп + НДС = DPAC × 1.22
  • Маржа % = ((ПЦ − Закуп с НДС) / ПЦ) × 100%
  • Нов ПЦ = Закуп с НДС / (1 − Целевая маржа / 100)
