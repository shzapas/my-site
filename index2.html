Мульти-подотделы, обновление данных, поиск, корзина

📌 1. Мульти-выбор подотделов

Кликните на поле «Подотделы» — откроется список с чекбоксами. Отметьте несколько — они отобразятся бейджами. У каждого бейджа есть ✕ для быстрого удаления. Ctrl не нужен.

🔄 2. Обновить данные

После загрузки папки появляется кнопка «🔄 Обновить». Нажмите её — браузер сам перечитает те же файлы (если они обновились). Не нужно выбирать папку заново.

⚠️ Браузер запомнит файлы на время сессии. Если закрыть вкладку — придётся выбрать папку снова. Это ограничение безопасности браузера.

🔍 3. Поиск

Артикул / название / штрихкод. Мульти-поиск: 11067374, 487274164. Фильтрует все таблицы сразу.

🛒 4. Корзина

Галочки ☑ в таблицах → плавающая кнопка внизу справа → экспорт в текст / Sheets / Excel.

🧮 5. Загрузка и расчёт

Загрузите папку (гамма, резерв, УТО) → нажмите «ВЫЧИСЛИТЬ».

🎛️ 6. Фильтры

Магазин, Подотделы (мульти), ТОП, Запас (дн). Чипы: 100+ / 365+ / 0-15. Магазины для ТС — чекбоксы внизу.

💡 7. Ещё внутри

  • 📅 История расчётов
  • 📊 Sparkline топ-10 магазинов
  • 🛡️ Защита от двойного трансфера
  • 📗 Копирование для Google Sheets
